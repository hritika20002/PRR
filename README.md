A corporate satire arcade survival game where every task you complete trains your AI replacement.

## The Concept

Survive a corporate shift while balancing productivity, energy, upskilling, and an increasingly capable AI competitor.

Working harder makes you more productive. It also teaches your replacement how to do your job.

## Planned Features

- Fast-paced 60-second survival rounds
- Progressive AI rival behaviour
- Corporate satire and retro arcade visuals
- Desktop and mobile controls
- Shareable performance scorecards
- No mandatory account creation

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- HTML Canvas
- Vitest
- Vercel (planned deployment)
